# Erdogan Kaya - Personal Portfolio

A modern, responsive portfolio website showcasing my work as a Full Stack Developer.

## Features

- **Home Page**: Hero section with animated introduction and featured projects
- **Projects**: Grid display of development projects with descriptions and tech stacks
- **About**: Professional background, skills, and 7-day weather forecast for Arlington, TX
- **Guestbook**: Visitors can leave comments and sign their name
- **Contact**: Contact form for reaching out

## Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS, Framer Motion
- **Backend**: Node.js, Express
- **Database**: PostgreSQL with Drizzle ORM
- **Styling**: shadcn/ui components, Radix UI primitives

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set up the database:
   ```bash
   npm run db:push
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

The app will be available at `http://localhost:5000`.

## Environment Variables

- `DATABASE_URL` - PostgreSQL connection string
- `SESSION_SECRET` - Secret for session management
